## 少做重复工作

此前 `SKILL.md` 从 943 个空白分隔词精简到 651 个，约减少 31%。后续[路线决策改版](route-search-pilot.md)增加了主循环中有用的选择标准，当前为 841 个词。保留任务契约、评分核验、预算、候选证据、独立确认和交付要求；按题型与当前动作读取详细参考，避免每轮加载所有工具说明。

新增的决策原则是先做便宜的有效分数比较，再按当前问题使用误差切片、profile、bootstrap 或训练重复。明显被否定的候选保留拒绝证据；排名接近、误差互补或机制不明确时再做相应诊断。以各阶段实测成本安排预算，并复用仍满足依赖条件的 baseline、来源和中间产物。

例如，只改集成权重可复用成员预测；只修正评分公式可复用未变的模型与预测，但重算评测；改 split 或训练特征需要重做依赖该变化的拟合和预测。固定预测 bootstrap 的缓存不允许跨模型、split 或配置盲目复用，也不会把旧开发证据变成独立确认。

规则见 [实验效率](../skills/competition-optimize/references/score-search.md#avoid-work-that-cannot-change-the-next-decision) 和 [预测缓存依赖](../skills/competition-optimize/references/data-model.md#establish-training-and-validation-evidence)。这些流程调整尚未单独测量完整 agent 的时间或提分效果。

## 区分真实实现改动与随机输出差异

复核发现两个实际误判：原实现把预测字节和训练配方合并成一个候选指纹，同代码的随机输出差异会被算成多个实现；而提案后继检查把所有配置文件都当作训练流水线，算法源码改动却可能因配置不变而被拒绝。五个针对性用例在旧版全部复现了失败。

保留产物指纹，并自动推导独立的实现身份。已声明的预测 CSV 或其他生成产物使用完整代码/配方快照作为实现身份；直接评测的算法源码则与其配置共同标识实现。`record` 自动关联先前同实现观测，`brief` 和 `decide` 按同契约首个有效实现观测判断代表和进步；随机测量、路线名或输出类型名称变化不会制造新方法。分数聚合与晋升仍服从任务的测量协议，所有原始结果和消耗保留。

输出文件不能冒充代码目标；组合提案也不能用任何一个父版本的原配方加新预测冒充新组合。缺少执行配方的旧产物仍保留分数和字节身份，独立实现数量显示为未知，后续代码改动需先核对实际执行快照。已存旧链接保持原接受范围并标明证据缺口，不要求改写历史。新增信息由工具推导，CLI 没有增加必填参数。

## 在组合前检查目标函数方向

原表格示例以“双方各有开发胜例”作为尝试等权组合的条件。该条件既可能鼓励无效组合，也可能错过较弱模型的价值。新增可选 [`--check-blend-direction`](../skills/competition-optimize/references/data-model.md#check-whether-a-two-parent-blend-has-a-useful-direction)，对两份固定开发预测检查 RMSE 的 MSE 损失或 MAE 损失的端点向内导数符号。两个端点均为负时，存在严格超过双方的理想内部组合；端点非负时，该父模型已是这条凸组合线段上的最小值。检查不生成权重、组合预测或组合分数，没有暗中执行权重搜索。

手算反例覆盖了两种错判：目标 `[0,0]`、基线 `[1,2]`、候选 `[4,1]` 双方各赢一行，但任何凸组合都无法超过基线 RMSE；基线 `[1,1]`、候选 `[-2,2]` 时，候选没有逐例胜出，仍可帮助某些内部组合。后一例等权组合反而更差，因此“存在有益方向”不能代替一次有预算的配方试验。精确有理计算保留解析浮点输入的符号，在极值、微小值、抵消及 MAE 零残差处可核验；只报告理想实数运算的方向，CSV 舍入及官方评测仍需另测。LogLoss 裁剪与 AUC 不适用这些判据，工具明确返回不可用。

新增 10 项测试包含 200 组固定种子的随机小案例，对照独立的精确最小值计算，并检查父模型互换、默认模式不变、开发/证据限制、摘要及 CLI；全套 144 项测试与 skill 校验通过。复用两题各 3 组真实开发对照，回归的 3 组方向均与独立残差内积计算一致；分类的 3 组均报告不支持该检查。默认统计、配置与 CSV 字节和修改前一致，原输入 hash 未变；此核对没有模型拟合、新配方或权重评分。脚本及 `audit.json` 在 `D:\华为云\tmp\blend-direction-review-20261010-01`。

示例流程接入该检查及摘要诊断后，以同样的切分、seed、模型和等权配方复跑；12 份评分及预测字节、两题交付选择均不变，分别与 sklearn 计分核对。6 次拟合和 2 个原配方用于集成验证，产物与独立检查在 `D:\华为云\tmp\blend-direction-pilot-20261010-01\integration-audit.json`。本次真实回归对照均仍有组合方向，没有据此减少实际配方次数；尚未测量完整 agent 的净时间、试验节省或提分。按当前决策需要启用检查，其额外计算计入诊断成本，实际配方仍逐项计 trial。
