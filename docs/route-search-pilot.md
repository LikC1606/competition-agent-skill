# 从参数变体转向路线搜索

本轮修改的是主决策流程：先比较不同解题路线，再选择路线内的改进。一个候选可以替换完整方法或耦合流水线，不限制为一个小补丁。路线图保存在 `research.md`，恢复卡保留当前路线、可负担的最强替代路线和选择理由；结果仍由冻结的指标与验证协议决定。

决策依据来自已有的[研究](automation-and-solving-experience.md)：MLE-STAR 的方法检索与组件深入、EoH 的新机制/机制修改/参数修改区分，以及算法获奖复盘中的表示和编码变化。本轮未重新运行这些上游项目，也未把特定算法写成跨任务默认方案。

## 主流程的变化

- **先选路线，再选变体。** 可执行的小调参不会自动压过有依据、可负担的结构性替代方案；约束、已有测量或预算使替代路线不值得测试时，记录原因即可。
- **一次候选承载完整机制。** 模型和预处理、表示和解码器、搜索表示和邻域可以作为一个完整方法一起替换。先评测整体，只有归因会影响下一步投资时才做消融。
- **按观测决定深入或换路。** 有明确改进空间时继续深入；连续微调收益微小或同一失败机制未解决时，返回表示、数据/训练信号、算法或策略选择，而不是继续生成相邻参数。
- **预算限制投入，不限制改动大小。** 未指定预算时仍是最多三个候选的初始搜索；已有授权、已耗预算与确认保留不变。更大的高分搜索需要明确预算，并非无限自动试验。

这改变了 `SKILL.md` 的决策循环、`score-search.md` 的路线选择与候选定义，以及 `decision-loop.md` 的恢复路由。它没有增加通用搜索服务器、自动提交或多 agent 依赖。

## 算法端到端试验

新增标准库示例 [`algorithm_route_pilot.py`](../examples/algorithm_route_pilot.py)，用生成的二维闭环旅行路线问题展示不同候选粒度。指标是所有案例路径长度的算术平均，越低越好；每条路径必须恰好访问每个顶点一次并回到起点。这是合成代理任务，不是实际比赛评分或通用 TSP adapter。

开发有 18 个实例：均匀、四簇、狭长三种几何分布，规模 `60/100/160`，各两个固定 seed，起始 seed `4100`。确认有 12 个实例：相同三种分布、规模 `80/140`，各两个新 seed，起始 seed `9100`。确认坐标在短名单冻结后生成；每组只确认 baseline 与其开发最优配置，按事先声明的“开发与确认均改善，否则 baseline”规则交付。

| 搜索组 | 六个候选名额的使用 |
| --- | --- |
| 参数组 | 最近邻 baseline，以及五个不同固定起点 |
| 路线组 | 同一 baseline、最远插入、MST 前序；从开发最好的构造路线继续测试 2-opt、增加顶点迁移、迁移后再次边交换 |

baseline 缓存只执行一次，但在两组各计一个名额，共 11 个不同开发配置。所有解法都从输入坐标完整运行，不能将父候选计算免费排除。每个局部搜索阶段最多检查 50,000 个可行邻域动作，整个候选最多 150,000 次检查；该工作上限不等同于统一时间预算。

## 实际结果

以下为固定协议第一次运行，未更换 seed、规模或候选来挑选结果。

| 路线组开发候选 | 平均路径长度 |
| --- | ---: |
| 最近邻 baseline | 8.610295 |
| 最远插入 | 7.370369 |
| MST 前序 | 9.395113 |
| 2-opt | 7.318718 |
| 增加顶点迁移 | 7.276493 |
| 迁移后再次边交换 | **7.275144** |

参数组的五个起点变体均未超过开发 baseline，因此冻结并交付 baseline。路线组选择最远插入作为局部搜索的起始构造，冻结最终邻域组合。

| 冻结候选 | 确认平均路径长度 | 相对 baseline 的确认改善 |
| --- | ---: | ---: |
| baseline / 参数组最优 | 8.922748 | 0% |
| 路线组最优 | 7.378855 | **17.30%** |

多数开发收益来自构造方法替换，后面的邻域深入带来更小的增益。这展示了路线选择和深入优化的不同作用，不意味着每次大改都应提分：MST 路线在这个开发集反而较差。

参数组与路线组开发评测累计分别约 `0.355 s` 和 `1.663 s`，路线组投入更多计算。计时包含距离准备、完整构造/搜索和逐例独立计分；不含 Python 启动、人工实现、方案选择、fixture 准备和完整交付成本。只能称为相同候选名额及相同工作上限的说明性对照，不能称为全部成本匹配的效率实验。
